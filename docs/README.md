# Tab Keeper PWA - Live Demo

This folder contains the **live PWA demo** for GitHub Pages.

## 🚀 Quick Test

1. Enable GitHub Pages for this repo
2. Settings → Pages → Source: `dev` branch → `/docs` folder (this folder!)
3. Access at: https://zant0p.github.io/tab-keeper/

## 📱 What This Is

- ✅ Working PWA (Progressive Web App)
- ✅ Installable on desktop/mobile
- ✅ Works offline
- ✅ No enterprise features (just testing)

## 🧪 Testing Checklist

- [ ] Opens in browser
- [ ] Install prompt appears
- [ ] Installs as standalone app
- [ ] Works offline (disconnect network, reload)
- [ ] All buttons work
- [ ] Timer counts down

## 🔍 Debug

- Service Worker: `chrome://serviceworker-internals/`
- Installed Apps: `chrome://app-internals/`
