## 🆘 Quick Help

### CRX Won't Install
- Check MIME type: `application/x-chrome-extension`
- Configure Enterprise policy (ExtensionInstallSources)
- See: `docs/CRX-ERROR-FIX-AZURE-GITHUB.md`

### PWA Won't Install
- Ensure HTTPS (or localhost for testing)
- Check manifest.webmanifest is valid
- See: `docs/PWA-WEB-BUNDLE-GUIDE.md`

### Need Web Bundle ID
- Run: `./scripts/build-pwa-bundle.sh`
- Requires: `npm install -g web-bundler`
